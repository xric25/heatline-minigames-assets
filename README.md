## 📂 Repository Contents

This repository hosts map files and assets for the Heatline Minigames Rust servers.

```
maps/           → Server map files
assets/         → Server assets
media/          → Images and media files
```

## 🗺️ Having Map Download Issues?

If your client fails to download the map automatically:

1. Download the map file from the [`maps/`](maps/) folder
2. Move it into your Rust game directory under the `maps` folder
3. Reconnect to the server
